## Описание проекта  

### Реализация  
- Реализовано с использованием композиции двух классов  
- Оверлей отображает область перекрытия элементов  
- Поддерживается копирование при клике  
- Можно встраивать в пользовательский интерфейс  
- Поддерживается создание нескольких экземпляров на странице  
- Доступна настройка параметров  

### Особенности  
- Настройки расположены в нижней части документа  
- Некоторым элементам добавлены CSS-классы, что позволяет переопределять стили с помощью `!important`  

### Тестирование  
- Проверена корректность расчёта координат (но не проводилось полное тестовое покрытие) 

### Принцип работы  
Основная задача — создание контейнера и заполнение его элементами `div` с обводкой.  
Правильное расположение обеспечивается за счёт:  
1. Алгоритма расчёта размеров каждого элемента  
2. CSS Flexbox с включённым `flex-wrap: wrap`  

### Стилизация  
Стили добавлены непосредственно в JavaScript, чтобы избежать конфликтов с внешними CSS-правилами.
